# 地方競馬のライブ観測

2つのターミナルで次のコマンドを実行し、[このPCの地方タブ](http://127.0.0.1:8787/#live/nar)を開きます。中央の収集や画面表示と並行で使えます。

```powershell
node --dns-result-order=ipv4first src/cli.mjs watch-nar
node src/cli.mjs serve
```

地方競馬情報サイトの当日一覧から開催場を発見し、各場のレース一覧と出馬表を照合します。発売中の単勝・複勝を、予定締切の10分前からおおむね10秒間隔で取得します。締切で各場の次レースに切り替え、観測済みのレースは「過去ログ → 地方」に表示します。「模擬 → 地方」では保存済みのレースを選んで締切前の動きを再生できます。 [地方競馬情報サイト](https://www.keiba.go.jp/KeibaWeb/TodayRaceInfo/TodayRaceInfoTop)

時間軸は楽天競馬の通常規則に従い、地方競馬情報サイトの予定発走の2分前を予定締切とします。画面は予定締切・予定発走・分精度の発表時刻・受信時刻を分けて表示します。締切以降の受信と「最終」表示は取り込み対象外です。 [楽天競馬の帯広ば当日レース一覧](https://keiba.rakuten.co.jp/odds/tanfuku/RACEID/202611070304160200)

初回確認では帯広ば・高知・佐賀を当日一覧から発見し、帯広ば11Rの発売中に馬名付き単勝・複勝の継続取得と画面表示を確認しました。10秒間隔は取得の試行周期です。発表時刻が同じ受信もあり、画面上の発表・受信時刻と欠損表示で鮮度を確認できます。

観測値はPC内の `data/observations.sqlite`、`data/nar-live.json`、`data/nar-history/` に保持します。公開版の地方タブからPC内の画面を開けます。地方競馬情報サイトの転載には事前許諾が必要です。公開配信に使う場合は地方競馬全国協会または主催者に利用範囲を確認してください。 [利用規約](https://www.keiba.go.jp/terms.html) · [二次利用の案内](https://www.keiba.go.jp/qa.html)

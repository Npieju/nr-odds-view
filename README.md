# 直前オッズ観測 — 締切前5分間のライブ収集・表示

**現在の入口は [ライブ観測の起動手順](docs/live.md) です。**

JRA公式Web（無料・ログインなし）を継続取得し、単勝・複勝の推移、最大下落／上昇、観測時刻を表示します。
JRA-VANは使用しません。Node.js 24、追加npm依存なし、組み込みSQLite。

```sh
node --test
node src/cli.mjs watch-jra data/race.local.json
# 別ターミナル
node src/cli.mjs serve
```

設定は上記手順を参照。画面は http://127.0.0.1:8787 。
取得は発売締切5分前から締切まで、既定10秒間隔。画面は1秒更新。
最終・確定・締切後受信はライブ集計へ入りません。

## 現状

実装済み: 発売中単複パーサー、有限時間の継続収集、元バイト保存、正規化・品質検査、SQLite蓄積、逐次JSON出力、最大変動集計、ライブ画面。
検証済み: 合成Shift_JIS応答からの取得・取込、5分窓の収集スケジュール、締切停止、変動集計、ブラウザ表示。
未検証: **現行の発売中公式ページでの直前5分間の取得と鮮度実測**。時刻表示は公開HTML例に基づき、未知の形式は拒否します。
未実装: 全開催自動発見、締切変更の自動反映、単複以外のHTMLパーサー、外部JSON配信。

生データとDBは `data/`（gitignore対象）。公開リポジトリにはソース・合成テストのみ。
従来の最終値取込・事後再生コードは互換性のため残っていますが、ライブ実行経路では使いません。
取得・集計・UIはまずローカル接続。公開配信の権利・品質を確認後にPagesと独立JSON配信へ進みます。

[調査履歴](docs/acquisition-research.md) は過去の調査記録です。JRA-VANを通常候補とした記述や、最終値取込を優先した計画は現在の方針ではありません。
